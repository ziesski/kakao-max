# 터미널에서 대화방을 골라 대화하기

`kakao shell`은 기존 계정 데몬에 연결하는 대화형 CLI입니다. 별도 카카오 로그인이나 새 카카오 계정 세션을 만들지 않습니다. 여기서 `cd`는 셸 안의 방 선택이며 카카오톡의 방 참여·나가기나 읽음 표시를 보내지 않습니다.

설치한 CLI 명령이 아직 없다면 저장소에서 다음처럼 실행합니다.

```bash
npm run kakao -- shell
```

CLI는 `MCP_HOST`와 `MCP_PORT`를 사용합니다. 원격 데몬에는 SSH 터널을 열고 로컬 CLI를 연결하세요. 예를 들어 데몬 포트가 8787이면 별도 터미널에서:

```bash
ssh -N -o ExitOnForwardFailure=yes -L 127.0.0.1:18789:127.0.0.1:8787 operator@server
```

다른 터미널에서:

```bash
MCP_PORT=18789 npm run kakao -- shell
```

원격 터미널에서 실행한다면 `ssh -t`로 TTY를 할당하세요. 셸 종료·Ctrl+C 시 MCP 연결을 닫습니다. 입력한 메시지를 파일이나 readline 명령 기록에 저장하지 않습니다.

## 명령 흐름

```text
kakao:/ > ls -al
kakao:/ > cd 프로젝트 모임
kakao:/프로젝트 모임 > 안녕하세요! 터미널에서 보내는 메시지입니다.
kakao:/프로젝트 모임 > history 30
kakao:/프로젝트 모임 > older
kakao:/프로젝트 모임 > cd ..
kakao:/ > exit
```

- `ls` / `ls -al`: 현재 데몬에 로드된 방 목록. 긴 목록은 방 종류·인원·안읽음 개수도 표시합니다. 마지막 메시지 미리보기와 숫자 방 ID는 출력하지 않습니다. 서버의 모든 과거 방을 발견한다고 보장하지 않습니다.
- `cd <방 이름>`: 공백이 있는 이름도 따옴표 없이 입력할 수 있습니다. `cd ` 다음 Tab으로 완성하고, 중복 이름이면 목록 번호로 고릅니다. `cd 2`는 목록 두 번째 방입니다. 화면에 표시한 이름과 목록 번호로만 선택하며 숫자 방 ID를 받을 수 있는 기존 단발 CLI와 다릅니다.
- 방 선택 후 최근 30개를 오래된 순서부터 표시합니다. 실패한 방 전환은 이전 수신 방도 해제해 잘못된 방으로 이어 보내지 않게 합니다.
- 방 안에서 일반 문장을 입력하고 Enter를 누르면 **실제로 전송을 요청**합니다. `ls`, `cd`, `history` 등 예약된 명령을 메시지로 보내려면 `/send ls`처럼 씁니다. `/`로 시작하는 문장도 `/send` 뒤에 넣습니다.
- `history [개수]`: 최근 1~100개 조회, 기본 30개. `older`: 직전 조회보다 오래된 기록을 같은 개수만큼 조회합니다. 이 기기가 받은 기록과 서버에서 제공하는 범위만 조회하며, 전체 과거 대화가 모두 있다고 보장하지 않습니다. 수신 메시지는 출력만 하고 명령으로 실행하지 않습니다.
- `pwd`, `help` 또는 `/help`, `clear`, `exit`: 현재 위치·도움말·화면 정리·종료. `clear`는 화면 정리이며 녹화나 터미널 스크롤백에 이미 나온 정보를 지운다고 보장하지 않습니다.
- 전송 성공 표시는 데몬 응답입니다. 상대 기기의 실제 도착과 구분합니다. 결과 불명·승인 대기 작업이 생기면 후속 전송을 막습니다. `/pending`은 기존 요청 상태만 조회하며 재전송하지 않습니다. 새 셸에서 같은 문구를 다시 입력해도 별도 요청이므로, 결과 불명 상태에서 재시작해 다시 보내지 마세요.

## 승인

기존 방별 읽기·전송 권한과 데몬 정책을 그대로 따릅니다. 일반 모드에서는 데몬이 보낸 승인 내용을 터미널에 표시합니다. 사람이 확인 코드를 직접 입력해야 하고, 빈 입력은 거절입니다. 필요할 때만 별도 질문에서 `y`로 해당 방의 후속 작업을 허용할 수 있습니다. 전송 방 허가는 문구를 제한하지 않습니다.

대화 조회는 읽음 표시를 보내지 않습니다. 기존 unread·읽기 범위·일일 한도·일시정지 등 제한도 유지됩니다. 이 CLI가 모드나 한도를 변경하지 않습니다.

## 촬영 모드

```bash
npm run kakao -- shell --demo --show-room "공개할 방 이름"
```

- 다른 방은 `대화방 001` 같은 가명으로 표시합니다. 자동완성과 프롬프트에도 숨긴 실명이 나오지 않습니다.
- 공개 방은 이름이 정확히 일치하는 단일 방이어야 합니다. 다른 방은 목록 번호·가명으로도 열 수 없습니다.
- 공개 방 안의 다른 발신자는 `참여자 1` 같은 가명, 본인은 `나`로 표시합니다. 메시지 본문과 인원·안읽음 수치는 그대로이므로 공개해도 되는 자료인지 확인하세요. 본문 안에 쓰인 실명·연락처까지 자동으로 가리는 기능은 아닙니다.
- 촬영 모드에는 계정 정보가 포함된 승인 창·패스키 링크를 출력하지 않습니다. 필요한 권한은 녹화 전에 일반 모드에서 사람이 확인하세요. 촬영 모드 자체는 데몬의 접근 권한을 변경하지 않습니다.
- 터미널 창 제목·SSH 접속 명령·이전 스크롤백은 별도로 확인하세요. 화면용 가명은 계정이나 카카오톡의 실제 방 이름을 수정하지 않습니다.

읽기·전송·승인은 단위 및 로컬 fixture로 검증한 범위와 실계정 검증 범위를 [기능 매트릭스](../agent-capability-matrix.md)에서 구분합니다.
