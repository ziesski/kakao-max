# 작은 터미널 메신저

`kakao chat`은 사람이 방을 고르고 대화할 수 있는 간단한 화면입니다. 기존 명령형 CLI와 MCP는 그대로 사용하며, 메신저 화면도 같은 데몬의 도구를 호출합니다. 새 계정 로그인이나 데몬 재시작은 하지 않습니다.

저장소에서 실행:

```bash
npm run kakao -- chat
```

터미널을 가로 72칸·세로 14줄 이상으로 준비하세요. 원격 데몬은 [SSH 연결 안내](cli-chat-shell.md)를 따라 로컬 포트를 연결하고 `MCP_PORT`를 지정합니다.

## 사용 흐름

1. 왼쪽 목록에서 방 이름을 검색하거나 위·아래 방향키로 선택합니다.
2. Enter를 누르면 오른쪽에 최근 30개를 표시하고 입력창으로 이동합니다.
3. 문장을 작성하고 Enter로 전송합니다. 여기서는 `ls`나 `cd`도 메시지 본문으로 보냅니다.
4. 선택한 방의 새 메시지는 데몬의 live feed를 약 2초마다 조회해 덧붙입니다. 작성 중인 문장은 유지합니다. 전송 중에는 추가 입력을 잠시 막아 작성 내용이 사라지거나 중복 제출되지 않게 합니다.
5. Tab 또는 Esc로 방 목록으로 돌아갑니다. 다른 방을 열면 작성 중인 문장은 초기화합니다.

PgUp/PgDn으로 현재 화면에 쌓인 대화를 스크롤하고, Ctrl+R로 현재 방의 최근 30개 또는 방 목록을 다시 조회합니다. Ctrl+C로 종료하면 커서·입력 모드를 복구하고 MCP 연결을 닫습니다. 붙여넣기 모드를 지원하는 터미널에서는 여러 줄을 붙여넣어도 전송하지 않고 한 줄로 합쳐 입력창에 넣습니다. 전송하려면 이후 Enter를 직접 누릅니다.

텍스트 대화의 최소 기능입니다. 파일·사진 첨부, 음성 통화, 자동으로 과거 기록을 계속 불러오는 기능은 포함하지 않습니다. 화면에 보관하는 메시지는 최대 500개이고, 오래된 모든 과거 기록이 조회된다고 보장하지 않습니다. 재시작으로 live feed가 바뀌거나 연결·권한 오류가 발생하면 자동 갱신을 멈추고 상태를 표시합니다. Ctrl+R로 재조회하거나 종료 후 다시 연결하세요. 자동 재로그인이나 전송 재시도는 하지 않습니다.

## 권한과 전송 결과

읽기·전송·읽음 표시는 기존대로 분리합니다. 화면 조회와 새 메시지 조회는 읽음 표시를 보내지 않습니다. 일반 모드에서 승인이 필요하면 요청 내용을 보여 주고 사람이 코드를 직접 입력합니다. PgUp/PgDn으로 긴 승인 내용을 볼 수 있고 빈 코드·Esc로 거절·취소합니다. 후속 작업 허용 질문은 기본값 N입니다. 계속 수신하려면 이후 조회에도 유효한 방 읽기 권한이 필요합니다.

전송 완료 표시는 데몬의 처리 응답이며 상대방의 실제 도착과 구분합니다. 결과가 불확실하면 입력 내용을 유지하고 새 전송을 막습니다. 화면을 다시 시작해서 같은 내용을 보내면 별도 요청이므로, 먼저 카카오톡과 기존 작업 상태를 확인해야 합니다.

## 촬영

```bash
npm run kakao -- chat --demo --show-room "공개할 방 이름"
```

다른 방 이름·발신자를 가명으로 표시하고 지정한 공개 방만 엽니다. 시스템 알림의 원본 메타데이터도 표시하지 않습니다. 공개 방의 일반 메시지 본문, 인원·안읽음 수치까지 익명화하는 기능은 아닙니다. 계정 정보가 포함될 수 있는 승인 화면은 촬영 모드에 표시하지 않으므로 필요한 권한을 녹화 전에 일반 모드에서 확인하세요. 촬영 모드 자체는 권한을 바꾸지 않습니다.

[명령형 대화 셸](cli-chat-shell.md)은 `kakao shell`로 따로 실행할 수 있습니다.
